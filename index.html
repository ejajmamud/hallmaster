10 · Business Rules (Figma Annotation Layer)

Paste each rule as a Figma sticky note on the relevant frame. They must be visible in the wireframe review.

R1 · Conflict prevention

  • A booking cannot overlap another approved or pending booking for the same hall.
  • Overlap definition: startA < endB && startB < endA (hour-level).
  • Show conflict inline at Step 2 and again on Submit.

R2 · Valid time range

  • Start hour must be strictly less than End hour.
  • Durations must be ≥ 1 hour.
  • Inline error field + disabled Continue CTA.

R3 · Edit permissions

  • User can edit only Pending or Approved future bookings.
  • Cancelled and past Completed bookings are read-only — Edit is hidden, Cancel is disabled.
  • Admin can edit any booking but sees audit note: “Edited by admin”.

R4 · Hall deletion

  • Hall cannot be deleted while it has active (pending or approved-future) bookings.
  • Surface the blocked state as a modal with a Deactivate alternative.

R5 · Role-based routing

  • Guest → cannot access /user, /booking/*, /admin. Redirect to /login.
  • User → cannot access /admin. Redirect to /login.
  • Admin → can access everything. Show role pill in app bar.

D · Component primitives

  • Button (Primary, Outline, Ghost, Danger) · variants: size (sm/md/lg), state (default/hover/pressed/disabled/loading)
  • TextField · variants: state (default/focus/error/disabled), size (sm/md), with/without leading/trailing icon
  • StatusChip · intents (success/warning/danger/info/neutral/brand) · sizes (sm/md)
  • Card · shadow-off / shadow-on
  • Avatar · size (sm/md/lg), initials / image
  • MetricTile · intent variants
  • TimelineSlot · state (free/selected/busy)

E · Compound components

  • AppBar · actions slot, subtitle slot
  • BottomNav · 3/4 items
  • NavRail · collapsed / expanded
  • HallCard · default, selected, inactive
  • BookingCard · by status
  • ConfirmDialog · neutral / destructive / blocked
  • EmptyState, ErrorState, LoadingState

F · Prototype flows

  • Guest discovery → Sign-in gate → Auth → User Home
  • User Home → Create Booking (3 steps) → Success → My Bookings
  • My Bookings → Detail → Cancel confirmation → Toast
  • Admin Home → Bookings → Review modal → Approved/Rejected toast
  • Admin Halls → Add/Edit modal; Delete → Blocked state when active bookings exist
