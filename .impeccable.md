## Design Context

### Users
- University project evaluators (grading demo quality and engineering depth)
- Event organizers and administrative staff using booking workflows
- Fast task completion is critical: discover halls, create bookings, review status, and manage operations with low friction

### Brand Personality
- Trustworthy
- Operational
- Premium
- Emotional goal: users should feel confident, in control, and informed at every step

### Aesthetic Direction
- Light-first enterprise dashboard style with clear hierarchy
- Modern Material 3 foundation with custom tokens, consistent spacing, and strong semantic states
- Clean, data-led visuals with restrained accent usage (no gimmicky effects)

### Design Principles
1. Clarity over decoration: every component should make booking and management decisions easier.
2. State transparency: loading, empty, success, warning, and failure states must always be explicit.
3. Action hierarchy: one clear primary action per section, with predictable secondary controls.
4. Form confidence: inline validation, contextual hints, and safe defaults to reduce user errors.
5. Production discipline: accessibility, responsiveness, and consistency across user/admin flows.
